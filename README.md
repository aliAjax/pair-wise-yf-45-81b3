# pair-wise-yf-45 影视剧组拍摄通告与资源冲突编排

源提示词摘要：为剧组制片、导演、演员统筹和场记提供通告编排工作台，维护场次、演员档期、场地与器材占用，自动发现资源冲突，支持拖拽排序、状态流转、版本快照、撤销恢复和离线草稿。

## 连续性账（造型 / 交接 / 失效重算 / 并发确认 / 重试队列）

- **造型连续性**：按剧情序为每场每角色记录服装、化妆、道具与收尾状态，上一场收尾状态带入下一场。
- **待补交接**：剧情相邻同角色场次之间生成交接账；跳拍（拍摄顺序颠倒）或上一场未开拍时列为待补。
- **失效重算**：场次拍摄日、演员或器材一改，依赖它的未开拍造型与交接立即失效重算；已开拍（拍摄中/已完成）场次留着现场。
- **并发确认**：两人同时确认同一场时先入账生效，后到拿到冲突编号（`LX-YYYYMMDD-NNN`）。
- **重试队列与幂等**：写入失败留重试队列；交接以幂等键去重，重复回传不生成第二份。

## 技术栈

Vue3、TypeScript、Vite、Element Plus、Pinia、Vue Router、Axios、VueUse、VeeValidate、Zod、Vue I18n、Day.js。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62010

## 页面

- `/` 通告编排：新增场次、拖拽排序、状态流转、版本快照、离线草稿、改期/改演员
- `/continuity` 连续性账：造型账、交接账、待补交接、冲突编号、重试队列、剧情序 vs 拍摄序
- `/conflicts` 冲突中心
- `/history` 版本历史与操作记录
